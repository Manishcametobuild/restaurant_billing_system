# Restaurant Order and Billing System

## About

This is a simple Restaurant Order and Billing System made using Python.

The program allows the user to view the menu, place an order, update the order, remove items, and generate the final bill.

It also shows simple sales statistics using NumPy.

## Features

- View restaurant menu
- Search food items
- Add food items to order
- Update item quantity
- Remove items
- Calculate total bill
- Apply discount
- Calculate GST
- Generate final bill
- Show sales statistics
